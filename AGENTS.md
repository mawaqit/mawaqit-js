# Instructions for AI agents

The official TypeScript library for the MAWAQIT API, the twin of
[mawaqit-py](https://github.com/mawaqit/mawaqit-py). Read [CONTRIBUTING.md](CONTRIBUTING.md) first.

## Rules

- Never edit generated files, which start with `// Generated by codegen/generate.ts`: change the
  spec in mawaqit/api-spec or `codegen/generate.ts`, then regenerate.
- The spec is private: never copy it, or parts of it, into this repository.
- Keep the behavior of mawaqit-py: same operations, errors, retries and Hijri dates. Names follow
  TypeScript conventions instead: camelCase, timeouts in milliseconds.
- Coverage stays at 100%, TypeScript stays strict, and `pnpm check` passes.
- `src/` has no runtime dependency and no Node.js API: only what every runtime with `fetch` has.
- Exported names have TSDoc comments. Comments explain what the code cannot: keep them short.
- Every change comes with tests, and type tests in `tests/types.test-d.ts` for the types.
